# คู่มือขึ้น production — v1.21.0 → v1.21.1 (แก้กรอบโปรไฟล์/กรอบแชทหาย)

**รายงาน (16 พ.ย. 2569):** "ตอนนี้มีบัคกรอบโปรไฟล์กับกรอบข้อความหาย และชวนแชทโลกไม่ได้โหมดวาดทายศัพท์"
**migration:** ไม่มี · ไม่แตะข้อมูลผู้ใช้

## สาเหตุ (กรอบหาย)
- v1.21.0 ที่ขึ้น production รอบแรกมีกรอบร้านค้าชุดแรก (`pf_mint` … `pf_sun`, `cf_mint` … `cf_gold`) ผู้ใช้ซื้อ/ใส่ไปแล้ว
- ตอนเปลี่ยนเป็นคอลเลกชันน่ารัก ผมถอด id ชุดแรกออกจาก `config/cosmetics.js` โดยเข้าใจผิดว่ายังไม่ขึ้นจริง → `users.profile_frame` / `chat_frame` ยังเก็บ id เดิม แต่ไม่มีภาพ (`frames.svg`) และสี (`cosmetics-frames.css`) ของ id นั้นแล้ว → กรอบหายจากรูปโปรไฟล์และฟองแชท · ข้อมูลในฐานข้อมูลไม่ได้หาย
- กรอบรางวัลเลเวลไม่ได้รับผลกระทบ

## แก้
- คืน id ชุดแรกทั้งหมดเป็น **"รุ่นแรก" (`source: 'retired'`)**: เจ้าของเดิมเห็น/ใส่/ถอดได้ตามเดิม · ไม่แสดงในร้านสำหรับคนที่ไม่มี · ซื้อใหม่ไม่ได้ (`RETIRED`) · ภาพและสีกลับมาใน `frames.svg` / `cosmetics-frames.css`
- หน้า "กรอบ & รางวัลเลเวล" มีหมวด "รุ่นแรกของคุณ" (แสดงเฉพาะเมื่อมี)
- กันพลาดซ้ำ: เทสต์ตรวจว่าทุก id ในคลังมีภาพ/สีจริง และ id ที่เคยออกขายต้องอยู่ในคลังตลอดไป (`test/endless_cosmetics.test.js`)
- ไฟล์: `public/css/endless.css` · `public/css/cosmetics.css` · `public/css/draw.css` (hover) · `services/worldChat.js` (คำเชิญ) · `config/cosmetics.js` · `services/cosmetics.js` · `public/js/cosmetics.js` · `public/assets/frames/frames.svg` · `public/css/cosmetics-frames.css` · `test/endless_cosmetics.test.js` · `config/changelog.js` · `package.json`

## ชวนแชทโลกในวาดทายศัพท์ — คำเชิญไม่ขึ้นจนกว่าจะออกแล้วเข้าใหม่
**รายงานเพิ่ม:** "กดชวนเพื่อนในแชทโลกแล้วไม่ขึ้นว่าชวน แต่เข้าแล้วออกใหม่ถึงจะขึ้น"
- **สาเหตุ:** เซิร์ฟเวอร์ส่งข้อความแชทโลกแบบสดให้ทุกคนที่ออนไลน์ *ยกเว้นผู้ส่ง* (`localFanout`) เพราะข้อความปกติหน้าแชทของผู้ส่งเพิ่มเองตอนกดส่ง — แต่คำเชิญถูกส่งจากหน้าวาดทายศัพท์ แชทโลกของผู้ส่งจึงไม่เคยได้รับ ต้องโหลดประวัติใหม่ (ออก/เข้า) ถึงเห็น · คนอื่นได้รับตามปกติ · ข้อมูลไม่หาย
- **แก้ (`services/worldChat.js`):** คำเชิญ (`postInvite`) ส่งกลับให้ผู้ส่งด้วย (`fanout(..., { echo: true })`) — รวมถึงกรณีหลายเครื่องเซิร์ฟเวอร์ (ส่งต่อผ่าน `pg_notify` พร้อมธง `e`) · ข้อความปกติไม่เปลี่ยน · หน้าเว็บตัดข้อความซ้ำด้วย id อยู่แล้ว และไม่นับเป็นข้อความยังไม่อ่าน
- ทดสอบ: `test/draw.test.js` (ผู้ชวนได้รับคำเชิญเดียวกันทาง WebSocket ครั้งเดียว) · `test/e2e/draw_invite_self_e2e.py` (390/820/1280: แชทโลกย่อและแชทโลกเต็มแสดงคำเชิญของตัวเองทันทีโดยไม่รีโหลด)

## ทายศัพท์ไม่รู้จบ: ตัวเลือกขึ้นกรอบหนาเองทั้งที่ยังไม่ได้กด (iPhone)
**รายงาน (21:08):** "บัคในโหมด endless ยังไม่ได้กดเลยขึ้นกรอบหนาแล้ว" (ภาพ: ตัวเลือกที่ 4 ขึ้นกรอบสีม่วง)
- **สาเหตุ:** บนจอสัมผัส (โดยเฉพาะ iOS Safari) สถานะ `:hover` ค้างอยู่ที่จุดที่เพิ่งแตะ — พอข้อถัดไปขึ้น ปุ่มที่อยู่ตำแหน่งเดิมจึงติดสไตล์ hover (กรอบสีหลัก) ทั้งที่ยังไม่ได้กด · เป็นแค่การแสดงผล ไม่ได้เลือกคำตอบ
- **แก้:** สไตล์ hover ใช้เฉพาะอุปกรณ์ที่มีเมาส์ (`@media (hover: hover) and (pointer: fine)`) — `public/css/endless.css` (ตัวเลือก) · `public/css/cosmetics.css` (การ์ดกรอบ) · `public/css/draw.css` (ปุ่มไอคอน + ปุ่มเลือกคำ) · โฟกัสด้วยคีย์บอร์ดยังมีกรอบตามเดิม
- ตรวจ: จำลอง iPhone 13 (สัมผัส) แตะคำตอบข้อ 4 / 2 / 3 → ตัวเลือกทุกปุ่มของข้อถัดไปเป็นกรอบสีปกติ
