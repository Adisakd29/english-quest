# คู่มือขึ้น production — v1.18.1 → v1.18.2 (รูปโปรไฟล์ตัวละครค้างเป็นโมเดลเก่า)

**ประเภท:** แพตช์ · **ไม่มี migration** · ไม่แตะ inventory / ชุด / Coin / EXP
**คำขอ (8 พ.ย. 2569):** "โมเดลตัวละครยังเป็นโมเดลเก่าอยู่เลยครับ ช่วยตรวจสอบให้ทีครับ"

## สิ่งที่ตรวจพบ
1. **รูปโปรไฟล์ตัวละคร (avatarThumbnail) ไม่ผูกกับรุ่นของโมเดล** — รูปนี้คือภาพ portrait ที่หน้าเว็บถ่ายจากโมเดล 3D ตอนผู้ใช้กดบันทึกชุด แล้วใช้แสดงในกระดานอันดับ แชท รายชื่อเพื่อน แถบด้านบน
   เดิมถือว่ารูป "ยังใช้ได้" ตราบใดที่ชุดไม่เปลี่ยน (`thumb_outfit_hash` = แฮชชุด) → ผู้ใช้ที่บันทึกชุดไว้ก่อนอัปเดตโมเดล (สไตล์หัวโตตัวเล็ก · ชุดใหม่ 2 พ.ย.) และไม่ได้เปลี่ยนชุดอีก **จะเห็นตัวละครโมเดลเก่าค้างอยู่ทุกที่ที่ใช้รูปนี้** (หน้าแต่งตัว/ร้าน/หน้าแรกที่เป็น 3D สดเป็นโมเดลใหม่แล้ว)
2. ในโปรเจกต์มีโค้ด **ร่างตัวละคร v2** (`scripts/avatar3d/blender/body_v2.py` — ผิวชิ้นเดียว ไม่มีรอยต่อ มือมีนิ้วโป้ง · 3 พ.ย.) ที่ **ยังไม่เคยถูก export ใช้งาน** (ต้องตั้ง `EQ_BASE_V2=1` ตอน build)
   ทดลอง build เต็มชุดแล้ว (Blender 5.0.1 · 147 ชิ้น): **ไม่ผ่านด่านตรวจ 23 ชิ้น** (เสื้อยืด/โปโล 9 แบบ — ผิวต้นแขนทะลุแขนเสื้อ 7.5–8% ในท่าแพ้ · กระโปรง 2 แบบ 26% ท่านั่ง · รองเท้าบูต/หุ้มข้อ 8 แบบ · ผ้าพันคอ · ผ้าคลุม · กางเกงเล 1) + มีรอยขรุขระที่คอ/ถุงเท้า และสัดส่วนหัวเล็กลง (ไม่ตรงสไตล์หัวโตตัวเล็กที่ใช้อยู่)
   → **ไม่ได้นำขึ้น** (ของ 23 ชิ้นจะใช้แบบ 3D ไม่ได้) · โมเดลที่ใช้งานยังเป็นชุดเดิม (ตรวจผ่านทุกชิ้น) · ไฟล์ทดลองไม่ได้ใส่ใน zip

## สิ่งที่แก้
- `services/avatar/index.js`
  - `thumbKey(outfit)` = แฮชชุด 12 ตัว + **แฮชรุ่นโมเดล 4 ตัว** (ไฟล์ GLB ของร่าง + ของทุกชิ้นที่สวม) — เก็บใน `thumb_outfit_hash` (VARCHAR(16) เดิม)
  - รูปที่ชุดตรงแต่รุ่นโมเดลไม่ตรง: **คนอื่นยังเห็นรูปเดิม** (ไม่ตกไปเป็นภาพ 2D) · เจ้าของได้ `avatarThumbnailStale: true` ใน `/api/avatar/me`
  - เพิ่มของใหม่ในร้านไม่ทำให้รูปหมดอายุ (นับเฉพาะชิ้นที่สวม)
- `public/js/avatar.js` `refreshStaleThumb()`: เปิดแอป 4 วินาทีแล้ว ถ้าใช้ Avatar เป็นรูปโปรไฟล์ และรูปเก่า/ยังไม่มี → เรนเดอร์ 3D นอกจอ (คิวเดียวกับแท่นรางวัล · WebGL ทีละตัว) ถ่าย portrait แล้วอัปโหลดผ่าน `POST /api/avatar/thumbnail` เดิม (ตรวจชุด/ไฟล์ภาพที่เซิร์ฟเวอร์เหมือนเดิม) · ครั้งเดียวต่อการเปิดแอป
- รูปของผู้ใช้แต่ละคนอัปเดตเมื่อ **เจ้าของ** เปิดแอปครั้งถัดไป (เซิร์ฟเวอร์เรนเดอร์ 3D เองไม่ได้)

## ขั้นตอน
Deploy ตามปกติ (ไม่มี migration) · ตรวจ: บัญชีที่ใช้ Avatar เป็นรูปโปรไฟล์ → เปิดหน้าแรก รอ ~5 วินาที → รูปที่แถบด้านบน/กระดานอันดับเป็นโมเดลปัจจุบัน

## ข้อจำกัด
- ผู้ใช้ที่ไม่ได้เปิดแอปเลยหลังอัปเดต รูปยังเป็นโมเดลเดิมจนกว่าจะเข้ามา
- เครื่องที่แสดง 3D ไม่ได้ (ไม่มี WebGL) ถ่ายใหม่ไม่ได้ → ยังใช้รูปเดิม
- รูปตัวอย่างของ "ชุดโปรด 3 ช่อง" (เห็นเฉพาะเจ้าของ) ยังเป็นภาพตอนบันทึกช่องนั้น
