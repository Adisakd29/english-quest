## สิ่งที่เปลี่ยน
### Learning Streak
- **นับ 1 วัน** = ตอบครบ 20 ข้อในวันนั้นตามเวลาไทย (`answer_events` ฝั่งเซิร์ฟเวอร์ — เกณฑ์เดียวกับเป้าหมายรายวัน/Coin DAILY_GOAL เดิม) · หน้าเว็บส่งจำนวนวันเองไม่ได้
- Migration `074_learning_streak.sql`:
  - `streak_days (user_id, day, kind goal|freeze)` · `streak_freezes` · `user_streaks (best, synced_day)` · `streak_milestones`
  - **เติมย้อนหลัง:** วันที่เคยตอบ ≥ 20 ข้อ หรือเคยได้ Coin เป้าหมายรายวัน → `streak_days` · `best` คำนวณจากประวัติ (gaps-and-islands)
  - ⚠️ การเติมย้อนหลังสแกน `answer_events` ทั้งตารางครั้งเดียว (GROUP BY ผู้ใช้/วัน) — ตารางใหญ่ใช้เวลาเป็นนาทีได้ ควรรันนอกช่วงคนใช้เยอะ
- `services/streak.js` (`sync` ทำใน transaction + ล็อกแถว `user_streaks`):
  1. บันทึกวันที่ทำครบ (ดูย้อนจากวันที่ sync ล่าสุด −1 วัน · ไม่เกิน 30 วัน)
  2. **Streak Freeze:** เดินย้อนตามสาย streak — เจอช่วงที่ขาด (≤ 2 วัน) และมี Freeze ที่ซื้อไว้ **ก่อนหรือในวันที่ขาด** พอครอบทั้งช่วง → ใช้ Freeze (วันนั้นเชื่อมไว้แต่ไม่นับเพิ่ม) · ไม่พอ → streak ขาด และ Freeze ไม่ถูกใช้ทิ้ง · ซื้อย้อนหลังมาซ่อมไม่ได้
     (ครอบกรณีไม่ได้เปิดแอปในวันที่ขาด แต่กลับมาทำเป้าหมายวันถัดไป)
  3. streak ปัจจุบัน (นับถึงวันนี้ ถ้ายังไม่ทำวันนี้นับถึงเมื่อวาน = "เสี่ยงขาด") + best
  4. Milestone 3/7/14/30/60/100/365 วัน (`config/streak.js`) — **ตาม streak ปัจจุบัน** (ไม่แจกจาก streak เก่าที่ขาดไปแล้ว) · ได้ครั้งเดียวต่อระดับตลอดไป
     รางวัล: Coin `STREAK_MILESTONE` key `streak:<วัน>` (15–1,000) + EXP `grantOnce('streak:<วัน>')` (30–1,500) · ล้มกลางทางแล้วเรียกครั้งถัดไปจ่ายส่วนที่ค้าง (idempotent)
- API `routes/streak.js` (`/api/streak`, ต้องล็อกอิน · userId จาก token):
  - `GET /api/streak` สถานะเต็ม (เรียกจากหน้าแรกทุกครั้งที่เปิด — ตรวจ Coin เป้าหมายรายวันให้ด้วย)
  - `POST /api/streak/freeze` ซื้อ Freeze — **50 Coin · ถือได้ 2 อัน** (ค่าจากเซิร์ฟเวอร์ · ล็อกกระเป๋า · Coin ไม่พอ 402 · ครบ 409 · 6 ครั้ง/นาที) · ธุรกรรม `STREAK_FREEZE` ยอดติดลบ
  - `POST /api/streak/seen` ปิดการฉลอง Milestone
- โปรไฟล์: field `achievements` (สิทธิ์การมองเห็นเดิม) มี `streak { current, best, badge }` → ตราบนโปรไฟล์ตัวเอง/ผู้อื่น
- หน้าเว็บ `public/js/streak.js` + `css/streak.css`: ชิปบนแถบหน้าแรก · การ์ดในคอลัมน์ซ้าย (7 วัน + ความคืบหน้าวันนี้ + Freeze) · หน้ารายละเอียด (bottom sheet บนมือถือ) ปฏิทิน 28 วัน / ซื้อ Freeze / ตรา 7 ระดับ · ป๊อปอัปฉลองตราใหม่
- ไอคอนใหม่ใน sprite: snowflake, calendar-check, calendar-x
