# TOEIC — วิเคราะห์จุดอ่อน (Patch 1.10.0)

หน้า `#/toeic-weak` (การ์ด "วิเคราะห์จุดอ่อน" ในหน้า TOEIC และลิงก์จากหน้าผล Full Mock Test)

## ทำอะไร
- รวมคำตอบของผู้ใช้จากทุก Part (Practice + Mock ที่ส่งแล้ว) แล้วจัดกลุ่มตาม **กลุ่มทักษะที่แต่ละ Part ใช้อยู่แล้ว**
  | Part | กลุ่ม |
  |---|---|
  | 1 | การกระทำ · สิ่งของ/สภาพ · บุคคล/จำนวน · สถานที่ · ตำแหน่ง/บุพบท · Passive |
  | 2 | Wh- · Yes/No · A or B · Tag · ปฏิเสธ · บอกเล่า · ขอร้อง/เสนอ |
  | 3, 4 | ภาพรวม · รายละเอียด · อนุมาน · เจตนา · กราฟิก |
  | 5 | รูปคำ · กริยา · สรรพนาม · เปรียบเทียบ · บุพบท · คำเชื่อม · คำศัพท์ |
  | 6 | ไวยากรณ์ · คำศัพท์ · บริบท · เติมประโยค |
  | 7 | รายละเอียด · อนุมาน · คำศัพท์ · NOT · แทรกประโยค · เชื่อมหลายเอกสาร |
- **ควรฝึกก่อน** 3 อันดับ พร้อมเคล็ดลับต่อกลุ่ม (เขียนเองใน `services/toeic/weakness.js`)
- ตัวเลือกหลอกที่พลาดบ่อย (Part 1–2 มีข้อมูลประเภทตัวเลือกหลอก) · กลุ่มที่ยังไม่เคยฝึก (คละ Part) · ตารางราย Part พร้อมแนวโน้ม 8 ข้อล่าสุด และลิงก์ทบทวนข้อผิด
- ช่วงเวลา: ทั้งหมด / 30 วันล่าสุด

## การให้คะแนนจุดอ่อน
- ความแม่นยำปรับด้วยค่าตั้งต้น: `(ถูก + 0.7×4) / (ตอบ + 4)` → กลุ่มที่ตอบน้อยข้อไม่ถูกตัดสินว่าอ่อน/เก่งเกินจริง
- ตอบ < 3 ข้อ = "ข้อมูลยังน้อย" · < 60% = ต้องฝึก · < 78% = พอใช้ · ที่เหลือ = ดี
- เป็นเกณฑ์ที่ตั้งขึ้นเองเพื่อจัดลำดับการฝึก ไม่ใช่การวัดระดับอย่างเป็นทางการ

## ชุดฝึกจุดอ่อน
- Practice ปกติของ Part นั้น + `group` (P2/P5 แมปเป็น `focus` เดิม) และ `drill: true`
- ขนาด: P1/P2/P5 10 ข้อ · P3/P4/P7 3 ชุด · P6 2 บทความ
- `group` ตรวจกับรายการกลุ่มของ Part (`Object.keys(...).includes`) — ค่าแปลก/คีย์ prototype ถูกละเลย · Mock ไม่รับ `group`
- EXP/Coin ตามกติกา Practice เดิม ไม่มีรางวัลพิเศษ
