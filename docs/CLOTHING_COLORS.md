## 1. Root Cause ของปัญหาฮู้ด / "เสื้อทุกตัวมีฮู้ด"
| อาการ | สาเหตุจริงในโค้ด | แก้ |
|---|---|---|
| ฮู้ดเป็นหมอน/ปลอกคอ ใหญ่ผิดธรรมชาติ คลุมหัวไม่ได้ | `garments.hood()` เดิมสร้างจาก **ทรงรี 1 ลูก** (`ellipsoid 0.155×0.11×0.085`) ตัดครึ่งหน้า + **ท่อหนา 12 มม.** ตามขอบ = วงแหวนพองรอบคอ · ตั้งอยู่ในช่วงคอที่ถูกขยายตามหัว (style_warp Z0–Z1) จึงพองออกอีก | เขียนใหม่เป็น **ผืนผ้าพับรูป Λ** (`fold_loft`): ผ้าซับในตั้งจากตะเข็บคอ → ขอบเปิดหน้าฮู้ด (ท่อบาง 3 มม.) → ผ้าด้านนอกพาดลงหลังเป็นถุงฮู้ด ยอดมนด้านล่าง · ตะเข็บกลาง · รอยยับตามแรงโน้มถ่วง · เชือก + ตาไก่โลหะ |
| เสื้อที่ไม่ใช่ฮู้ดก็ดูเหมือนมีฮู้ด | (1) ขอบคอเสื้อยืด/สเวตเตอร์เป็น **ท่อกลมหนา** (`edge_trim … trim_r×1.25`) (2) ปกโปโล/เชิ้ต = แผ่นแบน 2 ชิ้น + **`ring('collar_band')` ท่อหนา 9 มม.** รอบคอ (3) บอมเบอร์/วาร์ซิตี้ = `ring('collar_rib')` ท่อหนา 14 มม. (4) ปกแจ็กเก็ต/ลาเพลตั้งสูงถึงคอ ถูกขยายตามหัวเป็น "ปีก" สองข้างหัว (5) **หัวแขนเสื้อโผล่สูงกว่าโดมไหล่ ~7 ซม.** เป็นก้อนเหลี่ยมคล้ายขอบฮู้ด/เกราะไหล่ | ตัดท่อกลมรอบคอทั้งหมด → ขอบคอผ้าริบแบน (`neck_band`) · ปกเสื้อจริง (`fold_collar`: ขาตั้งปก + ปกพับ + ปลายปก + ตะเข็บทับ) · ลำตัวเสื้อทรงไหล่ใหม่ (`torso_shell`) คลุมหัวแขนเสื้อ |
| ฮู้ดมองไม่เห็นจากด้านหลัง / ตัวดูไม่สมดุล | หัวใหญ่ (×1.17) นั่งทับไหล่ ไม่มีคอ — บังปก/ฮู้ดทั้งหมด | สัดส่วน v3.1: หัว ×1.08 + คอสั้น 4 ซม. (`STYLE.KH/LIFT` ใน eqlib.py) |

ไม่มี Hood Up animation ในเกม จึงทำเฉพาะสถานะ Hood Down (ฮู้ดพับลงหลัง) — ไม่มีฮู้ดคลุมหัวที่จะชนผม/หมวก

## 2. Clothing Mesh ที่แก้ (`scripts/avatar3d/blender/`)
- `garments.py`: `torso_shell` (ใหม่ — ลำตัวทรงไหล่ แทน capsule โดม) · `yoke_surface` (ผิวเสื้อแบบพารามิเตอร์ ใช้วางฮู้ด/ปก) · `fold_loft` (ผ้าพับ Λ) · `hood` (เขียนใหม่) · `fold_collar` 4 แบบ (shirt / polo / camp / jacket) · `neck_band` (ขอบคอผ้าริบแบน · เปิดหน้าสำหรับเสื้อซิป) · `shirt_body` (ตัวเลือก `neck_trim`) · `sleeve` (เส้นทางใหม่ใต้แนวไหล่) · กระเป๋าหลังกางเกงวางบนผิวสะโพกจริง (เดิมลอย 8 มม. โผล่ทะลุชายเสื้อ)
- `items_wear.py` / `items_halloween.py`: ใช้ปก/ขอบคอใหม่ทุกชิ้น · ลบท่อ `collar_band / collar_rib / collar_top / cape_trim`
- `eqdetail.py`: ผ้าใหม่ `poly` (โพลีเอสเตอร์) · `nylon` (ริปสต็อป)
- `eqlib.py`: สัดส่วน v3.1 (KH 1.08 · LIFT 0.04)
- `build_avatar3d.py`: `color_regions()` → Material Region ต่อชิ้นใน meta/manifest
- `optimize.mjs`: ไม่ dedup material (ชื่อ material = Region) · manifest มี `regions`

## 4. Material Color Variants
- Region ต่อชิ้นคำนวณตอน build: ผ้าที่เปลี่ยนสีได้เรียงตามพื้นที่ผิว → `primary / secondary / accent` · **ตัดออกเสมอ**: โลหะ (metallic > 0.4) · ไฟเรืองแสง · ชื่อที่เป็นซิป/กระดุม/หมุด/ตาไก่/ด้ายเย็บ/พื้นยาง/ลายพิมพ์/โลโก้/ผิวหนัง · ส่วนที่เล็กกว่า 1.5%
- `config/avatarColors.js`: ชนิดเสื้อผ้า (GARMENT) · เนื้อผ้าที่เลือกได้ตามชนิด (ตัวแรก = เนื้อผ้าเดิมของชิ้น) · ชุดสี 16 สี · Color Picker · ชิ้นที่เปลี่ยนสีไม่ได้: ลายกาแล็กซี (ไล่สีด้วย vertex color) · ของรางวัล Achievement (เอกลักษณ์)
- Runtime (`public/js/avatar3d.js` `applyItemColor`): ย้อมเฉพาะ material ของ Region (ซิป/กระดุม/โลหะไม่ถูกแตะ) · เนื้อผ้า = ลาย normal map (procedural, UV triplanar ไม่ยืด/ไม่แตกเมื่อหมุน) + roughness (PBR) · ใช้ทั้งหน้าแต่งตัว โปรไฟล์ และ EnglishQuest World
- ไม่มีผลต่อการเล่น · ไม่เสีย Coin

## 5. การจัดเก็บ Color Configuration
- `user_item_colors (user_id, item_id, primary_color, secondary_color, accent_color, material_variant)` — ผูกกับของที่เป็นเจ้าของ (สวมชิ้นเดิมเมื่อไรก็ได้สีเดิม) · CHECK รูปแบบ `#rrggbb`
- `outfit_presets.colors` (JSONB) — สำเนาสีของชิ้นในชุดตอนบันทึก · ใส่ Preset = ตั้งสีกลับตาม Preset
- API: `PUT /api/avatar/colors/:itemId` (ตรวจเจ้าของ · Region · รหัสสี · เนื้อผ้า · ส่ง null = สีเดิม) · `GET /api/avatar/colors/palette` · `GET /api/avatar/me` → `colors` · Preset รับ/คืน `colors` · `looks` / โปรไฟล์ / World ส่งสีเฉพาะชิ้นที่สวม
