## เข้าใช้
- หน้าเรียน → ปุ่ม **ฝึกพูด · Speaking** (`#/speak`) · หน้าแรก → แถว **Speaking** ใน Learning Progress

- ฝึก (`#/speak-play/<setId>`): ฟังต้นแบบ ปกติ/ช้า → กดไมค์พูด → คะแนน 0–100 + คำรายคำ ชัด/ใกล้เคียง/ยังไม่ชัด (แตะคำเพื่อฟัง) → ก่อนหน้า/ถัดไป · สรุปท้ายชุด + ชุดถัดไป

## เนื้อหา (ดึงจากบทเรียนเดิม ไม่สร้างคลังใหม่)
| ระดับ | ประโยค | คำศัพท์ | บทสนทนา |
|---|---|---|---|
| A1 | 263 | 743 | 19 |
| A2 | 199 | 752 | 14 |
| B1 | 170 | 714 | 12 |
| B2 | 161 | 1259 | 9 |
| C1 | 208 | 1133 | 11 |
- ประโยค: ตัวอย่าง + ประโยคที่ถูกจาก "ข้อผิดพลาดที่พบบ่อย" ของแต่ละหัวข้อแกรมมาร์ (มีคำแปลไทย) · ตัดประโยคที่มีช่องว่าง/วงเล็บ/ยาวเกิน 20 คำ
- คำศัพท์: ชุดละ 10 คำจากคลังคำศัพท์เดิม พร้อม IPA และคำแปล
- บทสนทนา: บทสนทนา 2 คนจากบทเรียน → เลือกบทบาท เครื่องอ่านบทอีกฝ่ายแล้วไปต่อเอง เราพูดเฉพาะบทของตัวเอง (หรือฝึกทุกบรรทัด)

## การให้คะแนน (`public/js/speak-score.js` ใช้ร่วมกันหน้าเว็บ/เซิร์ฟเวอร์)
- ใช้ Speech-to-Text ของเบราว์เซอร์ (Web Speech API, 5 ตัวเลือก) → เทียบรายคำด้วย edit distance ระดับคำ
- ปรับมาตรฐาน: ตัวพิมพ์ · คำย่อ (I'm = I am) · ตัวเลข/ปี → คำ · คำพ้องเสียง (two/too/to ฯลฯ) · สะกด US/UK
- คะแนน = (ชัด + 0.6 × ใกล้เคียง) / จำนวนคำ × 100 − หักคำเกินเล็กน้อย · ผ่าน ≥ 70
- **ข้อจำกัด (บอกผู้ใช้ในหน้า Hub และหน้าขอใช้ไมค์):** วัดว่า "เครื่องฟังออกกี่คำ" ไม่ใช่การวิเคราะห์หน่วยเสียง/การเน้นเสียง/น้ำเสียงแบบครูตรวจ — เครื่องอาจเดาคำที่ออกเสียงไม่ชัดให้ถูกได้ หรือฟังผิดเมื่อมีเสียงรบกวน

## ความเป็นส่วนตัว / ความปลอดภัย
- แอปไม่อัดเสียง ไม่ส่งไฟล์เสียง และไม่ส่งข้อความที่ได้ยินมาที่เซิร์ฟเวอร์ — `POST /api/speak/attempt` รับแค่ `{itemId, score}` (E2E ตรวจ payload)
- ข้อความ "เครื่องได้ยินว่า" แสดงในเครื่องเท่านั้น
- ก่อนใช้ไมค์ครั้งแรกแจ้งว่าเบราว์เซอร์อาจส่งเสียงไปยังผู้ให้บริการ (Google ใน Chrome / Apple ใน Safari) · เลือก "ใช้ฟังแล้วพิมพ์" แทนได้
- userId จาก token เท่านั้น · rate limit 120/นาที · ตาราง `speaking_progress` เก็บเฉพาะคะแนนดีที่สุด/จำนวนครั้ง (ไม่มีคอลัมน์ข้อความหรือเสียง — มี test ตรวจ)
- คะแนนพูดมาจากเครื่องผู้ใช้ (ส่งค่าปลอมได้) → จำกัดผลกระทบ: EXP 2 ต่อประโยคเฉพาะครั้งแรกที่ผ่าน · เพดาน 40 EXP/วัน · **ไม่ให้ Coin** · ไม่นับเข้า Ranked
- ฟังแล้วพิมพ์: ตรวจคำตอบที่เซิร์ฟเวอร์

## สำรอง / ข้อผิดพลาด
- เบราว์เซอร์ไม่รองรับ (เช่น Firefox) → banner + เปิดโหมด **ฟังแล้วพิมพ์** อัตโนมัติ (ปุ่มพูดปิด)
- ไม่อนุญาตไมค์ / บริการไม่อนุญาต / ไม่มีไมค์ / เน็ตหลุด / ไม่ได้ยินเสียง → ข้อความไทยเฉพาะกรณี + ปุ่มเปลี่ยนเป็นฟังแล้วพิมพ์
- ออกจากหน้า / สลับแท็บ → หยุดไมค์และเสียงทันที
