# Deploy v1.25.3 — Christmas Photo Booth โฉมใหม่ · เพลงคริสต์มาสเล่นอัตโนมัติ

## สรุป
- **Photo Booth / Christmas Profile Card** ทำระบบสร้างภาพใหม่ทั้งหมด (`public/js/xmas-booth.js`)
  - ประกอบภาพเป็นชั้นแยก ควบคุมได้ทีละชั้น: ฉากหมู่บ้าน · ดาว · แสงบรรยากาศ · เงา · แสงสะท้อนพื้น · ต้นสน 3D · ไฟกะพริบ/ดาวบนยอด · ตัวละคร · ของขวัญ · หิมะ · กรอบ
  - ภาพ 3D ทั้งหมดสร้างเองด้วย Blender (Cycles) จากสคริปต์ `scripts/photobooth/build_booth_assets.py`
    - ต้นสนเป็นชั้นกิ่งห้อยตามธรรมชาติ มีกระจุกใบ หิมะเกาะ ลูกบอลแดง/ทอง ไฟ ริบบิ้น กระดิ่ง และดาว
    - กล่องของขวัญ และหมู่บ้านคริสต์มาสยามค่ำ (มีระยะชัดตื้นและหมอก)
  - ไม่มีรูปสามเหลี่ยม CSS หรือ polygon แบน
  - ส่งออกได้ 2 ขนาด: 1080×1350 และ 1080×1920
    - ภาพที่บันทึกคือ canvas เดียวกับภาพตัวอย่าง จึงตรงกันทุกพิกเซล (มีชุดทดสอบเทียบพิกเซล)
  - ตัวเลือกชุดในรูปแสดงเฉพาะไอเทมที่ผู้เล่นมีจริง (`/avatar/me` inventory) และไม่เปลี่ยนชุดในบัญชี
  - ต้นไม้และของขวัญจัดตำแหน่งจากกรอบทึบของตัวละครจริง จึงไม่ทับตัวละคร
  - ไฟล์ภาพเพิ่มใน `public/img/christmas/booth/` (WebP รวม ~1 MB) โหลดเฉพาะตอนเปิด Photo booth
- `avatar3d.js` `snapshot()` เพิ่ม option `{ format: 'png', ground: false }` ส่วนการเรียกแบบเดิมทำงานเหมือนเดิม
- **เพลงคริสต์มาส**: ไม่มีปุ่ม "แตะเพื่อเปิด" แล้ว ค่าเริ่มต้นคือเปิด
  - เบราว์เซอร์ยังบังคับให้เสียงเริ่มหลังการแตะ/คลิก/กดปุ่มครั้งแรกที่ใดก็ได้ในหน้า ข้อนี้เลี่ยงไม่ได้
  - ผู้ใช้กดหยุดแล้วระบบจำค่า `off` ไว้ทั้งในเครื่องและในบัญชี

ไม่มี (ไม่แตะฐานข้อมูล)

## ขั้นตอน
1. Deploy ตามปกติ (Railway build จาก repo)
2. ตรวจหลัง deploy:
   - เปิด `/img/christmas/booth/booth.json` ต้องได้ 200
   - ในช่วงคริสต์มาส: หน้า Christmas → Photo booth → ภาพแสดงภายในไม่กี่วินาที → บันทึกได้ทั้งสองขนาด
   - เปิดแอปใหม่ (บัญชีที่ไม่เคยปิดเพลง) → แตะหน้าจอครั้งแรก → เพลงคริสต์มาสดัง

## ย้อนกลับ (Rollback)
- Redeploy v1.25.2 ได้ทันที เพราะไม่มี migration และไม่มีข้อมูลผู้ใช้ใหม่
- ค่า `xmasMusic` ในบัญชีมีอยู่แล้ว (null/on/off) จึงเข้ากันได้ทั้งสองทาง
  - หมายเหตุ: v1.25.2 ตีความ null ว่า "ยังไม่เปิด" จึงจะกลับไปแสดงปุ่มแตะเพื่อเปิดเหมือนเดิม

## สร้างภาพใหม่ (ถ้าต้องการปรับ)
```
<python ที่มี bpy 4.2> scripts/photobooth/build_booth_assets.py /tmp/booth   # ~30–40 นาที บน CPU 2 คอร์ (EQ_LOW=1 = ตัวอย่างเร็ว)
python3 scripts/photobooth/pack_booth_assets.py /tmp/booth                    # → public/img/christmas/booth/*.webp + booth.json
```
