# สมาชิก Premium (Patch 1.10.0)

รายเดือน ฿39 / รายปี ฿299 · ชำระผ่านพร้อมเพย์ + แนบสลิป · **ตรวจสลิปกับธนาคารอัตโนมัติ (SlipOK)** หรือผู้ดูแลตรวจเอง

## ตั้งค่าก่อนเปิดขาย (Railway → Variables)
| ตัวแปร | ความหมาย |
|---|---|
| `PROMPTPAY_ID` | เบอร์มือถือ 10 หลัก หรือเลขบัตรประชาชน/ผู้เสียภาษี 13 หลัก ที่ผูกพร้อมเพย์ |
| `PROMPTPAY_NAME` | ชื่อบัญชีผู้รับที่แสดงให้ผู้ซื้อเห็น (ให้ตรงกับที่แอปธนาคารแสดง) |

ไม่ตั้ง `PROMPTPAY_ID` = ปิดการขาย (หน้า Premium แสดง "ยังไม่เปิดรับชำระเงิน") · ราคา/จำนวนวัน/สิทธิ์ แก้ที่ `config/membership.js`

## ผู้ใช้
1. โปรไฟล์ → **สมาชิก Premium** (`#/premium`) → เลือกรายเดือน ฿39 / รายปี ฿299
2. ได้ QR พร้อมเพย์ที่ **ใส่ยอดให้แล้ว** — ยอดมีเศษสตางค์เฉพาะคำสั่งซื้อ (เช่น ฿299.37) ไม่ซ้ำกับรายการที่ค้างอยู่ → ผู้ดูแลจับคู่ยอดเงินเข้ากับคนได้แน่นอน · บันทึกรูป QR เป็น PNG ได้
3. แนบสลิป (ย่อรูปในเบราว์เซอร์ ≤ ~1 MB) + เวลาที่โอน (ไม่บังคับ) → สถานะ "รอตรวจสลิป"
4. ผู้ดูแลอนุมัติ → Premium ทันที (+ แจ้งเตือน Push ถ้าเปิดไว้) · ปฏิเสธ → ผู้ใช้เห็นเหตุผล
- คำสั่งซื้อที่ยังไม่แนบสลิปหมดอายุใน 24 ชม. · ไม่ต่ออายุอัตโนมัติ · ต่ออายุ = ต่อจากวันหมดอายุเดิม

## ตรวจสลิปอัตโนมัติ (SlipOK)
ตั้ง `SLIPOK_API_KEY` + `SLIPOK_BRANCH_ID` (สมัครที่ slipok.com — มีค่าบริการตามแพ็กเกจของผู้ให้บริการ) · ไม่บังคับ: `PROMPTPAY_NAME_EN`, `PAYEE_ACCOUNT_SUFFIX`

เมื่อผู้ใช้แนบสลิป เซิร์ฟเวอร์ส่งรูปให้ SlipOK อ่าน QR บนสลิปแล้วถามธนาคาร → **อนุมัติทันทีเมื่อผ่านทุกข้อ**
1. ธนาคารยืนยันว่าสลิปจริง
2. ยอดเงินตรงยอดเฉพาะของคำสั่งซื้อ **ทุกสตางค์**
3. เวลาโอนไม่ก่อนสร้างคำสั่งซื้อ (เผื่อ 10 นาที) และไม่ใช่เวลาในอนาคต
4. ผู้รับตรงบัญชีเรา — เลขท้ายพร้อมเพย์/บัญชีที่ธนาคารแสดงแบบปิดบางส่วน หรือชื่อ (ชื่อต้นตรง + นามสกุลขึ้นต้นตรง)
5. เลขอ้างอิงธุรกรรม (transRef) ไม่เคยใช้กับคำสั่งซื้ออื่น (unique index)

ไม่ผ่านข้อใด / SlipOK ขัดข้อง → **ไม่ปฏิเสธเอง** รายการเข้าคิวผู้ดูแลพร้อมเหตุผล (ผู้ใช้เห็นเหตุผลด้วย) · ผู้ดูแลกด "ตรวจอัตโนมัติอีกครั้ง" ได้เมื่อระบบกลับมา

ทางเลือกที่อัตโนมัติ 100% (ไม่ต้องแนบสลิป): Payment Gateway เช่น Opn Payments — สร้าง QR ผ่าน API แล้วรับ webhook `charge.complete` · ต้องมีบัญชีร้านค้ากับผู้ให้บริการ (ยังไม่ได้ทำในแพตช์นี้)

## ผู้ดูแล
หน้า ผู้ดูแล → **สมาชิก Premium — ตรวจสลิป** · แท็บ รอตรวจ / ยังไม่แนบสลิป / อนุมัติแล้ว / ไม่ผ่าน
- **เทียบยอดเงินรวมเศษสตางค์กับรายการเงินเข้าในแอปธนาคารทุกครั้งก่อนอนุมัติ** (สลิปปลอมทำได้ง่าย — สลิปเป็นแค่ข้อมูลประกอบ)
- อนุมัติได้ครั้งเดียว · ปฏิเสธต้องใส่เหตุผล · อนุมัติรายการที่ยังไม่แนบสลิปได้ (กรณีเห็นเงินเข้าแล้ว)

## สิทธิ์ (ไม่ใช่ pay-to-win)
- ป้าย Premium ข้างชื่อ (โปรไฟล์ · กระดานอันดับ)
- ตัวช่วยรักษา Streak แผนฝึก TOEIC: พลาด 1 วัน (วันก่อนหน้าทำครบ) ไม่ขาด · เดือนละ 2 วัน · ใช้ได้ขณะเป็นสมาชิก
- **ไม่มี** EXP / Coin / เพดานรายวัน / ความได้เปรียบใน Ranked · ไม่ล็อกฟีเจอร์เดิมที่ใช้ฟรี

## ความปลอดภัย / ข้อมูลส่วนตัว
- userId จาก token เท่านั้น · ราคาและยอดคำนวณที่เซิร์ฟเวอร์ · ผู้ใช้เห็นเฉพาะคำสั่งซื้อของตัวเอง
- สลิป: ตรวจชนิดไฟล์จาก magic bytes (JPG/PNG/WEBP) · ≤ 1 MB · เก็บใน DB (ไม่อยู่ในโฟลเดอร์ public) · ผู้ดูแลเท่านั้นที่เปิดดู (`Cache-Control: no-store`) · **ลบรูปอัตโนมัติ 90 วันหลังตรวจ** (เก็บแค่ sha256 กันใช้สลิปซ้ำ)
- สลิปเดียวใช้ได้ครั้งเดียว · จำกัดสร้างคำสั่งซื้อ 5 ครั้ง/ชม. · สลิปรอตรวจพร้อมกันไม่เกิน 2
- ข้อความจากผู้ใช้/ผู้ดูแลตัด `< >` และอักขระควบคุม · หน้าเว็บ escape ทุกจุด

## ข้อจำกัด
- PromptPay ส่วนตัวไม่มีระบบแจ้งเงินเข้าเอง → ใช้ SlipOK ตรวจสลิปแทน · การเชื่อม SlipOK เขียนตามเอกสาร API สาธารณะ **ยังไม่ได้ทดสอบกับบัญชีจริง** — ทดลองซื้อจริง 1 ครั้งหลังตั้งค่า
- นโยบายคืนเงิน / ภาษีรายได้ — เจ้าของระบบต้องกำหนดเอง (ปรึกษานักบัญชี)
