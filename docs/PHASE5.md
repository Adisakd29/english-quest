## 2. กระดานอันดับ

ปัญหาที่พบจริง: ผู้ใช้ 809 จาก 1,109 คนมี 0 EXP และขึ้นอันดับ 1 ร่วมกันในกระดานตลอดกาล · `RANK()` ทำให้คะแนนเท่ากันได้อันดับซ้ำ · Ranked ทั่วโลกนับคนที่ไม่เคยแข่ง · บัญชีทดสอบปนกับผู้เล่นจริง

แก้:
- `ROW_NUMBER() OVER (ORDER BY score DESC, reached_at ASC, id ASC)` — คะแนนเท่ากัน ใครถึงก่อน (เวลา EXP ล่าสุดที่ทำให้ได้คะแนนนั้น) อยู่สูงกว่า
- ตลอดกาลนับเฉพาะ `exp > 0` · ผู้ที่ยังไม่มีคะแนนเห็นตัวเองเป็น "ยังไม่มีอันดับ"
- Ranked ทั่วโลกนับเฉพาะ `wins+losses+draws > 0`
- migration `065_test_accounts` เพิ่ม `users.is_test` (ค่าเริ่มต้น false — ไม่แตะข้อมูลเดิม) · ผู้ดูแลกดปุ่ม "บัญชีทดสอบ" ในหน้าจัดการสมาชิก (`POST /api/admin/membership/members/:id/test-flag`, บันทึก audit `test_flag_on/off`) · บัญชีทดสอบไม่ขึ้นกระดาน แต่เจ้าของยังเห็นอันดับตัวเอง
- หน้ากระดานมีข้อความอธิบายกติกาคะแนนเท่ากัน

ไม่ลบ/เปลี่ยน EXP, Coin, rank ของใคร — เปลี่ยนเฉพาะวิธีเรียงและกรองตอนแสดงผล

## 3. การ์ดการแจ้งเตือนค้าง "กำลังโหลด…"

สาเหตุ: `navigator.serviceWorker.ready` ไม่ resolve เลยถ้าไม่มี service worker ลงทะเบียน (โหมดส่วนตัวบางเบราว์เซอร์ / ถูกบล็อก / ลงทะเบียนล้มเหลว) → การ์ดรอตลอด
แก้: `swReg(timeoutMs)` ใน `public/js/notify.js` — ใช้ `getRegistration()` ก่อน ถ้าไม่มีจึงรอ `ready` แข่งกับ timeout · ใช้ใน `currentSub`, `enable`, `syncSubscription`
ทดสอบ: E2E รันด้วย `service_workers='block'` แล้วการ์ดต้องโหลดเสร็จภายใน 10 วินาที

## 4. WebSocket: เลิกส่ง JWT ใน URL

เดิม `wss://…/ws?token=<JWT>` — URL ถูกบันทึกใน log ของ proxy/เซิร์ฟเวอร์ได้ (JWT อายุยาว = ใครเห็น log ก็สวมรอยได้)
ใหม่:
1. เบราว์เซอร์ `POST /api/realtime/ticket` (ส่ง JWT ทาง header ตามปกติ) → `{ ticket, expiresIn: 30 }` (`Cache-Control: no-store` · จำกัด 60 ครั้ง/นาที)
2. ต่อ `/ws?ticket=<สุ่ม 32 ไบต์>` — ตั๋ว **ใช้ได้ครั้งเดียว** หมดอายุ 30 วินาที ผูกกับ userId + token_version (ออกจากระบบทุกอุปกรณ์แล้วตั๋วที่ออกไว้ใช้ไม่ได้)
3. `?token=` แบบเดิม: production ปฏิเสธ (401) · เปิดชั่วคราวได้ด้วย `WS_QUERY_TOKEN=on` · นอก production ยังใช้ได้ (ชุดทดสอบ/โหลดเทสต์)

ไฟล์: `realtime.js` (issueTicket/consumeTicket · ล้างตั๋วหมดอายุทุกรอบ heartbeat) · `routes/realtime.js` · `public/js/app.js` (rtConnect ขอตั๋วก่อน · ตัวนับรุ่น `rt.gen` กันตั๋วเก่าที่ค้างอยู่ตอนออกจากระบบ/ต่อซ้อน)
ข้อจำกัด: ตั๋วเก็บในหน่วยความจำ — ใช้ได้กับเซิร์ฟเวอร์เดียว (เหมือนสถานะออนไลน์/ห้องแข่งที่มีอยู่แล้ว) ถ้าขยายหลายเครื่องต้องย้ายไป Redis

## 5. CSP แบบบังคับ (enforce)

`CSP_MODE` ค่าเริ่มต้นเปลี่ยนจาก `report` → `enforce` (ยังส่งรายงานการละเมิดไป `/api/csp-report`) · ตั้ง `CSP_MODE=report` ชั่วคราวได้ถ้าพบปัญหาบน production
ก่อนเปิด: แก้ `public/offline.html` ที่มี `onclick` (inline handler ถูกบล็อกเมื่อบังคับ) เป็นลิงก์ธรรมดา
ตรวจด้วย `test/e2e/csp_e2e.py` (3 ขนาดจอ) — 51 หน้า + เล่นเสียง + ภาพ TOEIC + WebSocket + หน้าชำระเงิน + ผู้ดูแล + หน้าออฟไลน์ + Avatar 3D → การละเมิด 0 · JS error 0
ยังไม่ได้ตรวจ: ปุ่ม Google Sign-In (เครื่องพัฒนาไม่ได้ตั้ง GOOGLE_CLIENT_ID) — อนุญาต accounts.google.com ไว้แล้วใน script/style/frame/connect-src แต่ควรลองบน production
