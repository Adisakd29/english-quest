## ขั้นตอน
1. deploy ตามปกติ (migration รันเองตอนเปิดเซิร์ฟเวอร์)
2. เมนู "เล่น" → การ์ด "วาดทายศัพท์" (ป้าย "ใหม่") → สร้างห้อง → "ชวนในแชทโลก" → อีกบัญชีเปิดแชทโลกเห็นการ์ด → "เข้าร่วม"

## ความปลอดภัยและความเป็นส่วนตัว
- **คำเชิญในแชทโลก:** ข้อความแบบฟอร์มคงที่จากเซิร์ฟเวอร์ ("ชวนเล่น "วาดทายศัพท์" · ระดับ · x/8 คน · ห้อง CODE") + รหัสห้อง — ไม่มีข้อความพิมพ์เอง ไม่มีอีเมล/เบอร์/ตำแหน่ง · กติกาเดียวกับแชทโลก (ต้องเปิดแชทโลก · ถูกปิดแชท = ส่งไม่ได้ · จำกัดอัตรา) · ชวนได้ทุก 60 วินาทีต่อห้อง · การ์ดดึงสถานะห้องสด (รอผู้เล่น/กำลังเล่น/เต็ม/ปิด) และอัปเดตเองเมื่อห้องเปลี่ยน
- **ข้อมูลผู้เล่นที่ส่งออก:** id · ชื่อผู้ใช้ · รูปโปรไฟล์ (ตามระบบเดิม) · เลเวล · คะแนน เท่านั้น
- **คำตอบ:** เซิร์ฟเวอร์ส่งคำให้คนวาดคนเดียว · คนทายได้เฉพาะ `_ _ _` + ตัวใบ้ จนกว่าจะทายถูก · คำทายที่ถูกไม่ถูกส่งต่อ · คนวาด/คนที่ทายถูกพิมพ์คำตอบลงแชทไม่ได้ · แชทของคนที่ทายถูกแล้วเห็นกันเฉพาะคนวาด + คนที่ทายถูก
- **แชทในห้อง:** `utils/chatFilter` เดิม (ข้อมูลติดต่อ/ลิงก์ = ไม่ส่ง + นับรวมการปิดแชทอัตโนมัติ · คำหยาบ = ปิดด้วย *) · บันทึกลง `world_chat_log` (room = `draw:CODE`, mode = `draw`) เป็นหลักฐาน 30 วันเหมือนเดิม · ถูกปิดแชท = ยังทายได้ แต่ข้อความไม่ถูกส่งต่อ
- **คน:** บล็อกกัน (ทางใดทางหนึ่ง) = อยู่ห้องเดียวกันไม่ได้ (ไม่บอกว่าใครบล็อก) · เจ้าของห้องเชิญออกได้ (เข้าซ้ำไม่ได้) · ชวนเพื่อนได้เฉพาะเพื่อนที่ออนไลน์และไม่ได้บล็อกกัน
- **ภาพวาด:** ไม่ถูกเก็บ ยกเว้นตอนมีคนรายงานคนวาด → เก็บเส้นขณะนั้นใน `draw_report_evidence` ผูกกับ `user_reports` (เหตุผล: ภาพไม่เหมาะสม / เขียนตัวอักษรบอกคำ / ข้อความไม่เหมาะสม) · ผู้ดูแล: หน้า "จัดการเนื้อหา (ผู้ดูแล)" → รายงานผู้ใช้ → "ดูภาพวาดที่ถูกรายงาน"
- **เส้นวาด:** เฉพาะคนวาดส่งได้ · ตรวจพิกัด (0–1000 × 0–750) สี/ขนาดตามชุดที่กำหนด · ≤ 64 จุดต่อชิ้น · ≤ 24,000 จุดต่อตา · ≤ 60 ชิ้น/วินาที · คำทาย ≤ 60 ตัวอักษร ห่างกัน ≥ 0.6 วินาที ≤ 12 ครั้ง/15 วินาที

## แก้เพิ่มในแพตช์เดียวกัน (13 พ.ย. 2569) — เมนูเพื่อน/แชทซ้ำ + ปุ่มย้อนกลับในโปรไฟล์
**รายงาน:** "เมนูแชทและเพื่อนซ้ำซ้อนไหมครับ" · "ดูโปรไฟล์คนอื่นหน้ากระดานอันดับแล้วกดย้อนกลับชอบเด้งมาหน้าเพื่อน"
- **สาเหตุ (เมนู):** แชทในแอปคุยได้เฉพาะกับเพื่อน หน้าแชทว่างก็ลิงก์ไปหน้าเพื่อน และ HUD มีปุ่มแชทพร้อมป้ายข้อความใหม่อยู่แล้ว → การ์ด "แชท" ในหน้าเล่นซ้ำกับการ์ด "เพื่อน" (ใช้ภาพเดียวกันด้วย)
  - แก้: เหลือการ์ด "เพื่อนและแชท" ใบเดียว · หน้าเพื่อนและหน้าแชทมีแท็บ `เพื่อน | แชท` (`.fc-tabs`, `aria-current="page"`) พร้อมป้ายคำขอเป็นเพื่อน (`.fc-badge-fr`) และข้อความยังไม่อ่าน (`.fc-badge-chat`) · เส้นทาง `#/friends`, `#/chat`, ปุ่มแชทบน HUD ไม่เปลี่ยน
  - การ์ด "วาดทายศัพท์" เคยใช้ภาพเดียวกับ "ห้องแข่งคำศัพท์" → วาดภาพใหม่ `il-draw` (กระดานวาดรูป + พู่กัน + ฟอง "?") ต้นฉบับของแอป เพิ่มต่อท้ายใน `illustrations.svg` (ภาพเดิมไม่เปลี่ยน)
- **สาเหตุ (ย้อนกลับ):** ปุ่มย้อนกลับในหน้าโปรไฟล์ผู้เล่น (`#/user/ID`) เขียนตายตัวให้ไปหน้าเพื่อน
