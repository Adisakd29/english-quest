ภาพหน้าจอจริงที่ใช้ประเมินมาจาก `test/e2e/ui_shots.py`

## สิ่งที่แก้ใน v1.26.0 (แก้ซอร์สจริง)

**Global Snow** (`public/js/snow-fx.js`)
- เป็นเครื่องยนต์หิมะตัวเดียวระดับ App Shell ทำงานทุกธีม
  - ทดสอบแล้ว: ระบบ / สว่าง / มืด / พาสเทล / ฮาโลวีน / ดาราศาสตร์ / ลอยกระทง / คริสต์มาส
- มีการตั้งค่า เปิด/ปิด และความหนาแน่น น้อย/กลาง/มาก
- รองรับ reduced motion
- หน้าแบบฝึก/อ่าน/Quiz ใช้ระดับ low

**Snow-Covered Navigation** (`public/css/snow-caps.css` + `public/img/snow/*.svg`)
- สันหิมะ 2 ชั้นทรงธรรมชาติ มีแสงเงา (สร้างด้วยสคริปต์)
- ใช้กับแถบบน เมนูล่าง แถบข้าง และโลโก้
- มีก้อนหิมะเกาะมุมแผง
- ใช้ได้ทุกธีม: ธีมสว่างใช้ชุดสีของตัวเอง คริสต์มาสมีน้ำแข็งย้อย

**Home**
- Hero Scene ใช้ฉากหมู่บ้านหิมะที่เรนเดอร์ 3D แทนพื้นไล่สี
- มาสคอตจิ้งจอก
- ช่วงคริสต์มาสเพิ่ม:
  - ต้นสน 3D
  - ของขวัญ
  - พวงมาลัยไฟ
  - ประกายดาว
  - พวงหรีด (ที่การ์ดเทศกาล)
- แถบสถานะแบบ HUD: วงเลเวลทอง และแถบ EXP มีประกาย
- QuestCard แบบ RPG มีรางวัลจริง (EXP + Coin) และปุ่มรับรางวัล
- แอนิเมชันรับรางวัล
- จัดลำดับใหม่บนมือถือ
- แชทโลกย่อเป็นการ์ดในหน้า ไม่ลอยแล้ว
- กล่องยืนยันอีเมลใช้ดีไซน์เดียวกับการ์ดอื่น

**ปุ่มเพลงคริสต์มาส**: ฝังอยู่ในแถบบนบนมือถือ (ไม่ลอยทับเนื้อหาอีก)

**Design Tokens + Components** (`public/css/game-ui.css`)
- ตัวแปรระยะห่าง มุมโค้ง ตัวอักษร เงา และลำดับชั้น z-index กลาง
- คลาส GameCard, QuestCard, RewardCard, EventBanner, GameButton, ProgressBar, CurrencyBadge
- ธีมเทศกาลปรับผ่านตัวแปร `--g-*`

## เพิ่มใน v1.26.1
- **Learning Path** (ออกแบบใหม่ทั้งส่วนหัว):
  - หัวหน้าแบบฉากเกม
  - แถบ "คุณอยู่ที่" พร้อมปุ่มเรียนต่อ
  - ปุ่มลัดไอคอนอัญมณี
  - โลกแต่ละระดับมีแถบสีและความคืบหน้า
  - Unit ปัจจุบันขอบทอง
  - Boss การ์ดเด่น
- **Profile**: หัวโปรไฟล์ฉากเกม วงรูปทอง และเมนูไอคอนอัญมณี
- **Avatar / Ranked / Event Hub / Login**: ปรับขอบ มุม และเงาให้เป็นชุดเดียวกัน (เลย์เอาต์เดิม)

## เพิ่มใน v1.26.2
- **Ranked**:
  - เวทีประลองพื้นมืด
  - ตราแรงค์เรืองแสงสีประจำแรงค์ (ลอยขึ้นลงเบา ๆ)
  - ปุ่มเริ่มแข่งสีแดง-ส้มมีประกาย
  - ช่องสถิติเป็นแผ่นกระจก
  - ปุ่มลัดไอคอนอัญมณี
- **Login**: แผงต้อนรับเป็นฉากหมู่บ้าน 3D, ข้อความเรืองแสง, ปุ่มเข้าสู่ระบบสีทอง
- **Avatar**: หมวดที่เลือกเป็นปุ่มทอง และกรอบเวทีโค้งตามระบบ
- **รายการ Unit**: ผ่านแล้วเป็นสีเขียว, ล็อกจางลง, แถบสีประจำระดับ, node มีมิติ

## ยังไม่ได้ทำ (ระบุตามจริง)

- **Event Hub**: ยังใช้ดีไซน์เดิม (แผนที่ฉากกลางคืน — ได้คะแนนสูงสุด 4 อยู่แล้ว)
- **Avatar / Login**: ยังใช้โครงเลย์เอาต์เดิม (ปรับสี แสง และปุ่ม)
- **การทดสอบบนเครื่องจริง** (Android / iPhone จริง): ยังไม่ได้ทดสอบ
  - ทดสอบด้วยเบราว์เซอร์จำลองขนาดจอและ User-Agent มือถือเท่านั้น
