## สาเหตุ 1 — กรอบบนแถบด้านบนหายที่หน้าแรก
- หน้าแรก (ตัวละคร 3D) โหลด `/api/avatar/me` แล้วเรียก `setMyLook()` ใน `public/js/avatar.js` ซึ่ง **เขียนทับ "หน้าตาของฉัน" ใน cache โดยไม่มี `pframe`/`cframe`** → ทุกจุดที่แสดงรูปของเราถูกวาดใหม่แบบไม่มีกรอบ
- เมนูอื่นโหลดหน้าตาจาก `/api/avatar/looks` (มีกรอบ) กรอบจึงกลับมา — ทำให้ดูเหมือน "หายเฉพาะตอนกลับหน้าแรก" · เปิดแอปครั้งแรกที่หน้าแรกก็ไม่มีกรอบเช่นกัน

## แก้
- `services/avatar/index.js` `getMe()`: ส่ง `frames: { pframe, cframe }` (อ่านจาก `users.profile_frame` / `chat_frame` — เป็นข้อมูลของเจ้าของบัญชีเอง)
- `public/js/avatar.js`:
  - `setMyLook()` ใส่กรอบจาก `frames` และคงค่าเดิมไว้ถ้าไม่มีข้อมูล
