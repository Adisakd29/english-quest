# คู่มือขึ้น production — v1.9.0 → v1.10.0

ทดสอบจริงแล้ว (30 ต.ค. 2026): สร้างฐานด้วยโค้ด v1.9.0 + ผู้ใช้ 40 คน (คำศัพท์ 1,180 คำตอบ · แกรมม่า · ซื้อชุด Avatar · เพื่อน 17 คู่ ·
สมาชิก 4 คน รวมคนที่หมดอายุ · Ranked 20 คน · EXP เท่ากัน · ผู้ดูแลแก้คำศัพท์ 4 จุด) → บูต v1.10.0 (`NODE_ENV=production`) → ย้อนกลับ → v1.9.0 → อัปเกรดซ้ำ

| ผล | |
|---|---|
| Migration ใหม่ | 9 ไฟล์ (059–067) · บูต + migrate ~7 วินาที |
| ข้อมูลผู้ใช้ | 70/75 ตาราง เหมือนเดิมทุกแถว · ที่ต่างคือที่ตั้งใจ: `schema_migrations` · `vocab_senses` (เนื้อหาคำศัพท์ใหม่) · `toeic_questions` (+48 ข้อ Part 3/7) · `events` (บูตทุกครั้งอัปเดต `updated_at`) · `users` (เฉพาะ role ตาม `ADMIN_EMAILS` — พฤติกรรมเดิมของ v1.9.0) |
| ผู้ใช้เดิม | token เดิมใช้ต่อได้ (ไม่ต้องเข้าสู่ระบบใหม่) · ความคืบหน้า/EXP/Coin/ชุด/เพื่อน ครบ · สมาชิกเดิมวันหมดอายุไม่เปลี่ยน · คนที่หมดอายุแล้วแสดงเป็นไม่ใช้งาน |
| งานของผู้ดูแล | คำแปลที่ตรวจแล้ว / ความหมาย / ประโยคตัวอย่างที่ผู้ดูแลเคยแก้ (`content_edits`) **ไม่ถูกทับ** |

## 1. ก่อน deploy
- [ ] **สำรองฐานข้อมูล** (Railway → PostgreSQL → Backups หรือ `pg_dump "$DATABASE_URL" -Fc -f eq-before-1.10.0.dump`) — ทางย้อนกลับที่ปลอดภัยที่สุด
- [ ] ตั้ง `ADMIN_EMAILS` ให้ครบทุกคนที่เป็นผู้ดูแล (บูตทุกครั้งระบบตั้ง role ตามรายการนี้ — คนที่ไม่อยู่ในรายการจะกลายเป็นผู้ใช้ทั่วไป)
- [ ] ตรวจตัวแปรใหม่ (ทั้งหมดไม่บังคับ — ค่าเริ่มต้นใช้ได้):

| ตัวแปร | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| `CSP_MODE` | `enforce` | ถ้าพบหน้าเสียหลัง deploy ตั้ง `report` ชั่วคราว (ไม่ต้อง deploy ใหม่ แค่รีสตาร์ต) |
| `WS_QUERY_TOKEN` | ปิด (production) | `on` = ให้หน้าเว็บเวอร์ชันเก่าที่เปิดค้างต่อเรียลไทม์ได้ชั่วคราว (แนะนำ: ไม่ต้องเปิด — แค่รีเฟรชก็ใช้ได้) |
| `LEGACY_CARD_REVIEW` | ปิด (production) | `/api/progress/review` แบบเก่าตอบ 410 · `on` ชั่วคราวได้ |
| `PREMIUM_TRIAL_DAYS` | 7 | 0 = ปิดทดลองใช้ |
| `CARD_EXP_DAILY_CAP` | 600 | เพดาน EXP บัตรคำต่อวัน |
| `REGISTER_LIMIT_PER_HOUR` | 20 | สมัครต่อชั่วโมงต่อ IP |
| `PROMPTPAY_ID`, `PROMPTPAY_NAME` | — | ไม่ตั้ง = ปิดการขาย Premium |
| `SLIPOK_API_KEY`, `SLIPOK_BRANCH_ID` | — | ไม่ตั้ง = ผู้ดูแลตรวจสลิปเอง (**ตั้งใน Railway เท่านั้น ห้ามใส่ในโค้ด**) |
| `AI_PROVIDER`, `AI_API_KEY` | — | **ไม่ต้องตั้ง** — แอปไม่ใช้ AI แบบเสียเงิน |

- [ ] ไฟล์ที่ต้องอยู่ใน repo (ไม่ถูก .gitignore): `data/vocab-learner/` · `data/graded/texts.json` · `public/assets/graded/audio/` (14 MB) ·
  `data/toeic/part3/`, `part7/`, `academy/` · `scripts/learner/` · `scripts/rollback/` — **แคชเสียงระหว่าง build ไม่ต้อง commit** (`data/graded/clip-cache/` 150 MB อยู่ใน .gitignore แล้ว)

## 2. Deploy
1. Push โค้ด → Railway build (`npm ci --omit=dev` ใช้ได้ — โค้ดตอนรันไม่ใช้ devDependencies)
2. เซิร์ฟเวอร์เริ่ม → migration 059–067 รันเอง (log: `[migrate] รัน migration ใหม่ 9 ไฟล์สำเร็จ`, `[learner] อัปเดต 2975 …` และ `2972 …`)
3. ถ้า migration ใดล้ม เซิร์ฟเวอร์จะไม่เริ่ม (แต่ละไฟล์อยู่ในธุรกรรมของตัวเอง ไฟล์ที่ล้มไม่ถูกบันทึกครึ่ง ๆ) → ดู log แล้วย้อนกลับตามข้อ 4

## 3. ตรวจหลัง deploy (~10 นาที)
- [ ] `GET /api/health` → `{"ok":true,"version":"1.10.0"}`
- [ ] Header หน้าเว็บมี `Content-Security-Policy` (ไม่ใช่ `-Report-Only`) และ `Strict-Transport-Security`
- [ ] เข้าสู่ระบบด้วยอีเมล และ **ด้วย Google** (ยังไม่ได้ทดสอบภายใต้ CSP แบบบังคับ เพราะเครื่องพัฒนาไม่มี Google Client ID)
- [ ] มุมขวาบนแสดงจำนวนคนออนไลน์ (= WebSocket ต่อด้วยตั๋วได้) · เข้า World / Ranked ได้
- [ ] เรียนคำศัพท์ 1 Unit (เห็นประโยคตัวอย่าง + คำแปลไทย) · เรื่องอ่าน·ฟัง 1 เรื่อง (เสียงเล่นได้) · TOEIC Part 3 ข้อใหม่ (P3-0037 ขึ้นไป)
- [ ] หน้าสมาชิก Premium: สมาชิกเดิมยังแสดงวันหมดอายุถูกต้อง
- [ ] ผู้ดูแล: ตั้ง "บัญชีทดสอบ" ให้บัญชีของทีม (หน้าผู้ดูแล → สมาชิก Premium → ค้นชื่อ → ปุ่ม "บัญชีทดสอบ")
- [ ] 1–2 วันแรก ดู log `[csp]` (รายงานการละเมิด CSP) — ถ้ามีจากหน้าของแอปเอง แจ้งเพื่อแก้

## 4. ย้อนกลับ (ถ้าจำเป็น)
**ทางที่ 1 (แนะนำถ้าเพิ่ง deploy):** กู้ backup จากข้อ 1 แล้ว deploy โค้ด v1.9.0 — ข้อมูลที่เกิดหลัง deploy หาย
**ทางที่ 2 (เก็บข้อมูลผู้ใช้ที่เกิดหลัง deploy ไว้):**
1. หยุดเซิร์ฟเวอร์ (หรือ deploy โค้ด v1.9.0 ค้างไว้ยังไม่เริ่ม)
2. `psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -1 -f scripts/rollback/v1.10.0-to-v1.9.0.sql`
   - ย้อน migration 067 → 059 · คืนความหมาย/ตัวอย่างคำศัพท์เดิมจากตารางสำรอง · ซ่อนข้อสอบ TOEIC 48 ข้อที่ v1.9.0 ไม่มีไฟล์เสียง
   - **ไม่ลบ** บัญชี EXP Coin ของในกระเป๋า ความคืบหน้า เพื่อน สมาชิก คำตอบเดิม
   - **หาย:** ข้อมูลของฟีเจอร์ใหม่ (ความคืบหน้าเรื่องอ่าน·ฟัง · สถิติ Writing Studio · TOEIC Academy · รอบบทเรียนคำศัพท์ v2 · การทดลองใช้ Premium · `audit_logs` · ธงบัญชีทดสอบ)
3. เริ่มโค้ด v1.9.0 → log `[migrate] ไม่มี migration ใหม่ (รันไปแล้ว 58 ไฟล์)`
4. แก้ปัญหาแล้วอัปเกรดใหม่ได้ตามปกติ (migration รันซ้ำได้ · ข้อสอบที่ซ่อนเปิดกลับเอง)

- ปริมาณผู้ใช้จริง: ทดสอบอัปเกรดกับผู้ใช้ 40 คน + คำศัพท์ทั้งคลัง (migration คำศัพท์ไม่ขึ้นกับจำนวนผู้ใช้ จึงไม่น่าช้าลง)
