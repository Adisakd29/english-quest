**การตรวจคุณภาพ (บอกตามจริง)**
1. `scripts/tcas/validate.js` — โครงสร้างตาม blueprint · จำนวนข้อ · ตำแหน่งเฉลยกระจาย · ไม่ติดกัน 4 ข้อ · ตัวเลือกถูกไม่ยาวที่สุดบ่อยเกิน · ข้อความไม่ซ้ำข้ามชุด
2. `scripts/tcas/shuffle.js` (ใหม่) — สุ่มตำแหน่งตัวเลือกทุกชุด (ผู้เขียนหลายชุดวางเฉลยเป็นลำดับเดียวกัน → เดาได้) · ข้อหาจุดผิดไม่สลับ
3. Blind review — ผู้ตรวจ AI อีกตัวทำข้อสอบแบบไม่เห็นเฉลย 1–4 รอบต่อชุด แก้ทุกข้อที่ต่างหรือไม่แน่ใจ แล้วตรวจใหม่
   - ผลรอบสุดท้าย: 23/24 ชุดตอบตรงเฉลยทุกข้อ · TU-S3 ตรง 98/100 (ผู้ตรวจเลือกต่าง 2 ข้อโดยไม่มีเหตุผล ผู้ประสานงานอ่านเทียบบทความแล้วเฉลยถูก — บันทึกใน `review.note`)
   - AL-S7 ข้อ 071 และ AL-S8 ข้อ 048 ปรับถ้อยคำเล็กน้อย **หลัง** รอบสุดท้าย (เฉลยเดิม) — ยังไม่ได้ตรวจแบบ blind ซ้ำ
4. **ยังไม่ได้ตรวจโดยครูผู้สอน** — ทุกไฟล์บันทึกไว้ใน `review.method` · หากผู้ใช้แจ้งข้อผิด ผู้ดูแลซ่อนข้อได้ทันทีจากหน้าผู้ดูแล (ระบบเดิม)

**บอร์ดผู้สนับสนุน (ใหม่)**
- แอปไม่ได้เชื่อมกับ ezdn.app (ไม่มี API/Webhook ที่ตรวจแล้ว) → ผู้ดูแลนำเข้าเองที่ หน้าผู้ดูแล → "บอร์ดผู้สนับสนุน"
  - พิมพ์บรรทัดละ 1 คน แค่ `ชื่อ ยอด` ก็พอ (เช่น `NongFah 100` · ชื่อมีช่องว่างได้ ตัวเลขท้ายบรรทัดคือยอด) · ไม่ใส่วันเวลา = ใช้เวลาที่นำเข้า และนับเป็นโดเนทใหม่ทุกครั้ง (ตรวจก่อนนำเข้าจะเตือนถ้าชื่อ+ยอดนี้มีอยู่แล้ว)
  - ใส่ละเอียดได้: `ชื่อ | ยอด | วันเวลา | ช่องทาง` (คั่น `|` หรือ Tab) — มีวันเวลาแล้วนำเข้าซ้ำจะถูกข้ามให้เอง · วันเวลารับ `09 พ.ย. 09:28:15` (ไม่มีปี = ปีล่าสุดที่ไม่เกินวันนี้) · `2026-11-09 09:28` · `09/11/2569 09:28` · ตีความเป็นเวลาไทย
  - "ตรวจก่อนนำเข้า" แสดงตัวอย่าง/บรรทัดที่ผิดโดยไม่บันทึก · มีบรรทัดผิด = ไม่นำเข้าเลย · รายการซ้ำข้ามให้เอง · ครั้งละ ≤ 200 บรรทัด
  - ทุกการนำเข้า/ซ่อน/แสดง/เปลี่ยนค่าต้องใส่เหตุผล → `supporter_admin_logs`
- **ไม่เก็บข้อความโดเนท ชื่อบัญชีธนาคาร หรือข้อมูลติดต่อ** · ชื่อตัด `<` `>` และอักขระควบคุมตอนบันทึก + esc ตอนแสดง
- `GET /api/supporters` (ต้องเข้าสู่ระบบ) → อันดับ 20 คน: ชื่อ (สะกดตามรายการล่าสุด) · ยอดรวม · ระดับ (ทอง ≥ 500 · เงิน ≥ 100 · ทองแดง) · จำนวนครั้ง — ไม่มีช่องทาง/เวลา
  - ชื่อเดียวกัน (ไม่สนตัวพิมพ์/ช่องว่าง) รวมเป็นคนเดียว · ยอดเท่ากันเรียงคนที่สนับสนุนก่อน
  - ผู้ดูแลปิด "แสดงยอดเงินบนบอร์ด" ได้ (แสดงเฉพาะอันดับ + ระดับ) · ซ่อนรายการได้ (เช่น เจ้าตัวขอ) — ไม่มีการลบ
- หน้าแรก: การ์ด "บอร์ดผู้สนับสนุน" ใต้การ์ดสนับสนุน (5 อันดับ + ดูทั้งหมด) · ซ่อนเองถ้ายังไม่มีรายการ
- ไฟล์: `services/supporters.js` · `routes/supporters.js` · `public/js/supporters.js` · CSS ใน `public/css/visual.css` (+ ธีมเทศกาล)
