**รายงาน (23 พ.ย. 2569):** "หน้ากิจกรรมเนื้อเรื่องวันลอยกระทงบัค กดย้อนกลับแล้วย้อนไม่ได้กลับมาหน้าเดิม และ หน้า UI ฝั่ง tablet desktop เมนูซ้อนกัน"
**migration:** ไม่มี · แก้เฉพาะหน้าเว็บ (ไม่แตะข้อมูลผู้ใช้ ไม่ reset ฐานข้อมูล)

## สาเหตุ 1 — กดกลับแล้วไม่กลับหน้าเดิม
- หน้าเทศกาล → ปุ่ม "เริ่มอ่านเรื่อง/เริ่มฟังเรื่อง" เปิด `#/graded/A2-07/...` แต่ปุ่มกลับของหน้าเรื่อง **ตายตัวเป็น "เรื่องทั้งหมด"** → ไปรายการเรื่อง ไม่กลับหน้าเทศกาล
- ปุ่มกลับของหน้าเทศกาล (`#hf-back`) และหน้าตะลุยด่าน (`#ev-back`) ใช้ `history.back()` → ถ้าเพิ่งไปหน้าเรื่อง/หน้าอื่นจากหน้านี้ จะย้อนกลับไปหน้านั้น (วน) แทนหน้าที่เข้ามา

## แก้
- `public/js/app.js`: จำ hash ก่อนหน้า + `rememberOrigin(key)` (จำหน้าที่เข้ามา เฉพาะเมนูหลัก เช่น หน้าแรก/เล่น/เรียน/อันดับ ไม่จำหน้าลูก) + `goBackFrom(key)` (กลับหน้านั้น · ไม่รู้ = หน้าแรก) — เก็บใน sessionStorage ต่อแท็บ
- `public/js/festival.js` / `public/js/event.js`: เรียก `rememberOrigin` ตอนเปิดหน้า · ปุ่มกลับใช้ `goBackFrom`
- `public/js/graded.js`: เรื่องที่เปิดจากหน้าเทศกาล → ปุ่ม "กลับหน้าเทศกาล" (บนสุด + หลังส่งคำตอบ) · เปิดจากรายการเรื่องปกติยังเป็น "เรื่องทั้งหมด"
- ปุ่ม Back ของเบราว์เซอร์/ปัดย้อนของ iPhone ทำงานเหมือนเดิม (จากหน้าเรื่อง → หน้าเทศกาล)

## สาเหตุ 2 — เมนูซ้อนกันบนแท็บเล็ต/คอม
- หน้าตะลุยด่านแบ่ง 2 คอลัมน์ (แผนที่ + แผงภารกิจ) ตั้งแต่จอ 980px แต่พื้นที่เนื้อหาจริงแคบกว่ามาก (1024px ขึ้นไปมีเมนูซ้าย 240px · ก่อนหน้านั้นกล่องเนื้อหาจำกัดความกว้าง)
  → แผงภารกิจเหลือ ~100–180px ตัวหนังสือตกบรรทัดทีละคำ ป้าย "กำลังผจญภัย" ทับหัวข้อบท (เห็นชัดบน iPad แนวนอน 1024px)
- แก้ `public/css/event.css` + `WIDE_Q` ใน `public/js/event.js`: 2 คอลัมน์เฉพาะ ≥ 1200px · ต่ำกว่านั้นใช้แบบแตะจุดบนแผนที่ (เหมือนมือถือ)
