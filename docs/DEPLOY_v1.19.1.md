## ฟังบทสนทนา (ตัวเสริม)
- เฉพาะส่วน Listening & Speaking ของ A-Level: ปุ่ม "ฟังบทสนทนา" อ่านออกเสียงทีละบรรทัดด้วยเสียงสังเคราะห์ของเบราว์เซอร์ (`speechSynthesis` — ฟรี ไม่มี API ไม่ส่งข้อมูลออกนอกเครื่อง)
- ผู้พูดต่างคนใช้เสียงต่างกัน (ถ้าเครื่องมีเสียงภาษาอังกฤษหลายเสียง) หรือระดับเสียงต่างกัน · ช่องว่าง = เสียงบี๊บ (ไม่อ่านเฉลย ไม่อ่านชื่อผู้พูด) · ความเร็วปกติ/ช้า · หยุดได้ · เปลี่ยนกลุ่ม/ออกจากหน้า = หยุด · หรี่เพลงประกอบระหว่างอ่าน
- **แสดงบทสนทนาเป็นค่าเริ่มต้นเหมือนข้อสอบจริง** · ผู้เรียนเลือก "ซ่อนบทสนทนา (ฝึกฟังอย่างเดียว)" ได้ (จำค่าในเครื่อง) · ดูเฉลยหลังส่งเห็นบทสนทนาเสมอ
- เบราว์เซอร์ที่ไม่มีเสียงสังเคราะห์: ไม่แสดงปุ่ม (ใช้งานแบบอ่านได้ตามปกติ)
- TGAT1 Speaking และส่วนอ่าน/เขียนไม่มีปุ่มฟัง

- ตัดชื่อแบรนด์จริงที่หลงอยู่ ("gmail.com") และเปลี่ยนชื่อยิมปีนผาที่อาจซ้ำของจริง
