# ส่วนที่ 2 — Ranked: กันการโกงด้วย F12 / สคริปต์

**คำขอ (9 พ.ย. 2569):** "กด f12 โกงแต้มแรงค์ได้หรอครับ" → "แก้ให้หน่อยครับ อยู่ในเลขแพตช์เดิม ส่วนใครที่โกงเอาแรงค์คืนมาครับ"

## ตรวจพบจริง (ก่อนแก้)
- กันไว้แล้ว: เฉลยไม่ถูกส่งก่อนตอบ (NPC/PvP/ทีม) · เซิร์ฟเวอร์ตัดสินถูกผิด/จับเวลา/คิดคะแนนเอง (ส่ง `points`/`correct`/`elapsedMs` ปลอมไม่มีผล) · ตอบซ้ำ/ตอบข้อล่วงหน้า/ตัวเลือกนอกช่วง/เกมของคนอื่น = ถูกปฏิเสธ · เปิดเกมใหม่ทับไม่ได้
- **ช่องโหว่:** สคริปต์อ่านโจทย์ → ค้นความหมายจาก `/api/vocab/search` ของแอปเอง → ตอบทันที = ถูก 10/10 ใน 50–100 ms ได้ 9,985/10,000 คะแนน

## สิ่งที่แก้
| ส่วน | รายละเอียด |
|---|---|
| เกณฑ์ (config/leagues.js `INTEGRITY`) | `minHumanMs` 600 · `flagFastCorrect` 3 (ปรับได้ด้วย env `RANKED_MIN_HUMAN_MS`, `RANKED_FLAG_FAST_CORRECT`) |
| คะแนนต่อข้อ | ผู้เล่นตอบถูกเร็วกว่า 600 ms = ได้ 700 (ไม่มีโบนัสความเร็ว) · NPC ใช้สูตรเดิม (NPC/PvP/ทีม) |
| ตอนจบเกม (`applyOutcome`) | ตอบถูกเร็วกว่า 600 ms ≥ 3 ข้อ: ชนะ/เสมอ → แต้มแรงค์ ±0 · ไม่นับสถิติ · ไม่ได้ EXP · แพ้ → เสียตามปกติ · คู่แข่งผู้เล่นจริงที่แพ้ผู้โกง → ไม่เสียแต้ม · บันทึกใน `ranked_integrity_flags` |
| หน้าผล | แจ้งเหตุผลชัดเจน ("เกมนี้ไม่นับแต้มแรงค์และ EXP — ตอบถูกเร็วกว่า 0.6 วินาที N ข้อ…") |
| ระหว่างแข่ง | `GET /api/vocab/search` และ `/api/vocab/:id` ตอบ 423 `RANKED_IN_PROGRESS` · จบเกมแล้วใช้ได้ |
| ริบแต้มย้อนหลัง | `services/ranked/integrity.js` + `scripts/ranked/reclaim-cheat.js` + แผงแอดมิน (Ranked Analytics → "ความยุติธรรม") |

## ริบแต้มคืนจากคนที่โกง (ฤดูกาลปัจจุบัน) — **ไม่ทำอัตโนมัติตอน deploy**
สิ่งที่ทำเมื่อสั่ง:
- ผู้โกง: ริบ QR ที่ "ได้" จากแมตช์ผิดปกติ → ตำแหน่งแรงค์คิดใหม่จาก QR (ไม่สูงกว่าเดิม) · ยกเลิกสถานะรอเลื่อนขั้น · จุดสูงสุดของฤดูกาลคิดใหม่จากแมตช์ปกติ · ตัดจำนวนชนะของแมตช์ที่ถูกริบ
- คู่แข่งผู้เล่นจริง (PvP/ทีม) ที่แพ้ผู้โกง: คืน QR ที่เสียไป (ภายใน League เดิม — ขึ้น League ยังต้องผ่านแมตช์เลื่อนขั้น)
- **ไม่แตะ** EXP / Coin / ของในคลัง / ของตกแต่งที่ได้แล้ว / ประวัติแมตช์
- ทุกการปรับเก็บค่าก่อน-หลังใน `ranked_qr_reclaims` → คืนค่าได้ (ถ้าผู้เล่นแข่งต่อไปแล้ว คืนเฉพาะส่วนต่างแต้ม ไม่ทับผลงานใหม่)

ขั้นตอนแนะนำ:
1. deploy แล้วดูรายชื่อก่อน: แอดมิน → Ranked → Ranked Analytics → "ความยุติธรรม" หรือบนเซิร์ฟเวอร์ `node scripts/ranked/reclaim-cheat.js` (อ่านอย่างเดียว · รายงานรายแมตช์: ถูกเร็วกี่ข้อ เร็วสุด/เฉลี่ยกี่ ms)
2. ตรวจรายชื่อ — ถ้าสงสัยว่ามีคนจริงติดมา ปรับเกณฑ์ให้เข้มขึ้นก่อน (เช่น `RANKED_FLAG_FAST_CORRECT=5`)
3. ทำจริง: กดปุ่ม "ริบแต้มผู้โกง" 2 ครั้ง หรือ `node scripts/ranked/reclaim-cheat.js --apply` → ได้ batchId
4. ถ้าผิดพลาด: ปุ่ม "คืนค่า" ในแผง หรือ `node scripts/ranked/reclaim-cheat.js --revert <batchId>`

# ส่วนที่ 3 — EXP: กันบอทเก็บ EXP + ริบ EXP ย้อนหลัง

**คำขอ:** "ยังงี้ก็โกง exp ได้ด้วยสิ" → "ริบ exp คืนได้เลย อนุญาต" (9 พ.ย. 2569 01:20)

## ตรวจพบ
- Ranked: EXP ต่อเกม (ชนะ 20 + 2/ข้อถูก) ไม่มีเพดานรายวัน → บอทเล่นวนได้ไม่จำกัด (ส่วนที่ 2 ปิดเกมที่ตอบเร็วเกินมนุษย์แล้ว)
- หมวดเรียน: EXP "ครั้งเดียวต่อข้อ/ขั้น" หรือ cooldown 20 ชม./คำ → บอทเก็บ EXP ทั้งหมดที่คนขยันจะได้ในเวลาสั้นมาก (การ์ดคำศัพท์หลายพันคำ ไม่มีเพดานรายวัน)

## สิ่งที่แก้
| ส่วน | รายละเอียด |
|---|---|
| `utils/answerPace.js` + `users.last_answer_at` | ทุกคำขอ "ตอบข้อ" ที่ให้ EXP ประทับเวลาในฐานข้อมูล (ใช้ได้แม้มีหลายเซิร์ฟเวอร์ · คำขอพร้อมกันถูกเรียงด้วย row lock) |
| การ์ด/บทเรียนคำศัพท์/Word Atlas (`recordCardAnswer`) | ห่างจากข้อก่อนหน้า < 600 ms → EXP 0 (`noExpReason: 'too_fast'`) · ความคืบหน้า/SRS บันทึกตามปกติ · Word Atlas แบบจับคู่ประทับครั้งเดียวต่อคำขอ |
| EXP รายข้อของ grantOnce (`c2q` `glq` `c2x` `glx` `t1q` `t2q` `t5q` `t6q` `t7q`) | เร็วเกินมนุษย์ → EXP 0 **และไม่เผาคีย์** (ตอบใหม่ตามจังหวะคนยังได้) · คีย์จบขั้น/จบบท/สตรีคไม่ถูกตรวจ |
| หน้าเว็บ | ข้อความ "ไม่ได้ EXP — ตอบเร็วเกินกว่าคนอ่านโจทย์ทัน…" (การ์ด/บทเรียน/Word Atlas) |
| เกณฑ์ | `LEARN_MIN_HUMAN_MS` (ค่าเริ่มต้น 600) |
| **ไม่ได้เปลี่ยน** | เพดาน EXP รายวันของการ์ด (`CARD_EXP_DAILY_CAP`) และ Ranked (`RANKED_EXP_DAILY_CAP`) ยังปิดตามนโยบายเดิม (v1.13.0) — เปิดได้ด้วย env ถ้าต้องการ |

## ริบ EXP ย้อนหลัง (รวมอยู่ใน batch เดียวกับการริบแต้มแรงค์ · กดปุ่มเดียว / `--apply` ครั้งเดียว)
- **Ranked:** EXP ของแมตช์ที่ตอบถูกเร็วกว่า 600 ms ≥ 3 ข้อ (ทุกฤดูกาล) — จำนวนตาม `result.exp.gained` ของแมตช์นั้น
- **หมวดเรียน:** เฉพาะ EXP ของ "ข้อ" ที่ได้ห่างจากข้อก่อนหน้า (คนละคำขอ) < 600 ms · เฉพาะผู้ใช้ที่มีข้อแบบนี้ ≥ 10 ข้อ (`EXP_FLAG_MIN`) กันกรณีบังเอิญ
- ลด `users.exp` + ใส่แถวติดลบ `exp_log` (เหตุผล `integrity_reclaim`) **ลงวันที่เดิมของ EXP ก้อนนั้น** → กระดานรายสัปดาห์/เดือนย้อนหลังถูกต้อง ไม่ไปลบคะแนนสัปดาห์นี้
- กันริบซ้ำด้วย `exp_reclaim_refs` · บันทึกก่อน-หลังใน `exp_reclaims` · คืนค่า = เพิ่ม EXP กลับ + ลบแถวติดลบที่ระบบใส่เอง
- ไม่แตะ Coin / ของในคลัง / รางวัลเลเวลที่ได้ไปแล้ว (เลเวลคำนวณใหม่จาก EXP อัตโนมัติ)
