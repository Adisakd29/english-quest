# Deploy v1.26.3 — หิมะโหมดประหยัด (ตรวจเครื่องอัตโนมัติ)

ต่อจาก v1.26.2 (deploy ทับได้เลย)

## สรุปการเปลี่ยนแปลง
แก้เฉพาะ `public/js/snow-fx.js` ฝั่งเซิร์ฟเวอร์ไม่เปลี่ยน

**เข้าโหมดประหยัดเมื่อเข้าเงื่อนไขใดเงื่อนไขหนึ่ง:**
- เบราว์เซอร์วาดภาพด้วย CPU: ตรวจจากชื่อ WebGL renderer (SwiftShader / llvmpipe / Software / Basic Render) หรือไม่มี WebGL
- เวลาวาดหิมะจริงต่อเฟรม (มัธยฐาน 12 เฟรมแรก) เกิน 4 ms
- เฟรมรวมของหน้าช้าเกิน 30% ติดกัน 2 ช่วง (ไม่นับ 1.5 วินาทีแรกที่โหลดหน้า)

**สิ่งที่โหมดประหยัดทำ:**
- canvas ครึ่งความละเอียด
- ไม่มีชั้นหน้า
- วาด 30 fps
- หยุดวาดชั่วครู่ระหว่างผู้ใช้เลื่อนหรือลาก

**การบังคับโหมด** (ชุดทดสอบหรือผู้ดูแล): `localStorage.eq_snow_power = 'full' | 'low'`

**ชุดทดสอบ:**
- `global_snow_e2e.py`
  - ทดสอบโหมดปกติด้วยการบังคับ `full`
  - เพิ่มการทดสอบโหมดประหยัดบนเครื่องไม่มี GPU
- `xmas_e2e.py` / `xmas_snow_soak.py`: รับจำนวน canvas = 1 เมื่ออยู่ในโหมดประหยัด

**อัตราเฟรมหิมะ (แก้เพิ่มในแพตช์เดียวกัน):**
- มือถือ/แท็บเล็ต 60 fps เท่าคอมพิวเตอร์ (ก่อนหน้า 30)
- โหมดประหยัด 30 fps (ก่อนหน้า 20)
- วัดจริง (Chromium headless): บังคับโหมดเต็ม 60 fps ทั้ง 1280 และ 390 · โหมดอัตโนมัติบนเครื่องไม่มี GPU 30 fps
