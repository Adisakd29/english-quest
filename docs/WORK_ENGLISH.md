# ภาษาอังกฤษเพื่อการทำงาน — หมวดเฉพาะสมาชิก Premium (Patch 1.10.0)

หน้าเรียน → **ภาษาอังกฤษเพื่อการทำงาน · Premium** (`#/work`, `#/work/<topic>`)

## เนื้อหา
6 หัวข้อ × 12 วลี = 72 วลี (`data/premium/work/<topic>.json`) · ระดับ B1–B2 · เขียนใหม่ทั้งหมด (ไม่คัดลอก)
| หัวข้อ | id |
|---|---|
| อีเมลที่ทำงาน | emails |
| การประชุม | meetings |
| สัมภาษณ์งาน | interview |
| โทรศัพท์และวิดีโอคอล | calls |
| การนำเสนองาน | presentations |
| คุยกับลูกค้าและเพื่อนร่วมงาน | clients |

แต่ละวลี: phrase · คำแปล · วิธีใช้ · ระดับความสุภาพ (ทางการ/ทั่วไป/เป็นกันเอง) · ประโยคตัวอย่าง + คำแปล · ข้อสถานการณ์ (เลือกประโยค 4 ตัวเลือก) · ข้อเติมคำ (4 ตัวเลือก) · คำอธิบายทุกตัวเลือก

### ขั้นตอนตรวจเนื้อหา
1. `BRIEF.md` + ผู้เขียน 3 ชุด (ชุดละ 2 หัวข้อ)
2. `node scripts/work/validate.js` — โครงสร้าง · phrase อยู่ในตัวอย่าง · เติมคำแล้วได้ตัวอย่างเป๊ะ · ช่องว่างอยู่ในวลี · ตัวเลือกไม่ซ้ำ · กระจายตำแหน่งคำตอบ · ภาษาไทยไม่มีสระลอย · วลีไม่ซ้ำข้ามหัวข้อ
3. ผู้ตรวจ 2 ชุดทำข้อสอบ **โดยไม่เห็นเฉลย** — ตรงเฉลย 144/144 ข้อ ไม่มีข้อกำกวม
4. แก้ตามผู้ตรวจ: คำแปล/ระดับความสุภาพ/คำอธิบาย 19 จุด
- ข้อจำกัด: ยังไม่ได้ผ่านครูที่เป็นมนุษย์ · ตัวลวงในข้อสถานการณ์ค่อนข้างง่าย (ผู้ตรวจให้ข้อสังเกต)

## สิทธิ์
- ตรวจที่เซิร์ฟเวอร์ทุกคำขอ: สมาชิก Premium ที่ยังไม่หมดอายุ หรือผู้ดูแล (`services/work/index.js` → `canAccess`)
- ยังไม่เป็นสมาชิก: เห็นรายการหัวข้อ + ตัวอย่างหัวข้อละ 2 วลี · เริ่ม/ตอบแบบฝึก = 403 `PREMIUM_REQUIRED`
- เป็นเนื้อหาใหม่ทั้งหมด — **ไม่ได้ย้ายบทเรียนฟรีเดิมมาล็อก**

## แบบฝึก
- 10 ข้อ/ชุด ผสมสถานการณ์กับเติมคำ · เลือกวลีที่ยังไม่ชำนาญ/นานแล้วก่อน · สลับตำแหน่งตัวเลือกทุกชุด
- ไม่ส่งเฉลยก่อนตอบ · ตรวจที่เซิร์ฟเวอร์ · ตอบซ้ำไม่ได้ · ชุดของคนอื่นเข้าไม่ได้
- ชำนาญ = ตอบถูกติดกัน 2 ครั้ง (`work_progress.streak`)
- **ไม่ให้ EXP / Coin** — กันผู้ที่จ่ายเงินได้เปรียบในกระดานอันดับ
