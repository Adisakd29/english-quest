## การตรวจเนื้อหา (ก่อนตั้ง `review.passed: true`)

2. Blind solve รอบ 1 (ผู้ตรวจ AI ไม่เห็นเฉลย): ตรงเฉลย 100/100 · ไม่มั่นใจ 2 ข้อ (สำนวนอังกฤษ) → แก้ KP-S4-003 / KP-S4-020 + ลดความยาวคำตอบที่เด่นเกิน KP-S1-004 / KP-S4-021 / KP-S2-003
